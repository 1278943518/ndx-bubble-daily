# 长周期组合：回撤能不能"不减收益"地降下来？

> 数据：Shiller 百年数据库（1871-2026，含股息与长债利率）+ FRED DGS10 + 纳指月线  
> 口径：全收益（价格 + 股息），10Y 国债用久期近似（D=7.5）  
> 结论建立于**回测**，不是预测。历史不代表未来。



---

## 一句话答案

**在同一个资产池里做"股债配比"——没有免费午餐，每放弃 1pp 收益换回约 10pp 回撤。**  
**但换一个维度（时间维度分配风险预算、消除集中度风险）——有接近免费的办法，效率能提升 6～12 倍。**

我之前十几个版本的测试都在**择时**上打转（温度择时、趋势择时、多资产轮动），全部失败。这次换了个问题问法：不预测市场，只改变"我自己承担多少风险"。这才是长期组合真正的杠杆。

---

## 一、基础事实（1950-2026，76 年，全收益）

| 资产         | CAGR       | 年化波动  | 最大回撤       |
| ---------- | ---------- | ----- | ---------- |
| 标普 500 全收益 | **11.68%** | 12.0% | **-49.0%** |
| 10 年期国债    | 5.06%      | 6.8%  | -23.5%     |

**股债月收益相关性 0.08 —— 几乎零相关。**

更关键的一条：**股票表现最差的 45 个月里，债券平均 +0.4%。**  
（1926-2026 百年样本：股票最差 60 个月，债券平均 +0.5%；1871 年至今：+0.3%）

这就是分散化的全部秘密——不是"债券平时帮你赚钱"，而是**在你最痛的时候它不跟跌**。零相关 + 长期正收益 = 组合的回撤必然小于各部分回撤的加权平均。

---

## 二、一次性投入：明确的交易，不是免费的午餐

固定权重 + 年度再平衡，1950-2026：

| 股/债       | CAGR   | 波动    | 最大回撤   | Sharpe   | Calmar | 每放弃 1pp 收益换回 |
| --------- | ------ | ----- | ------ | -------- | ------ | ------------ |
| 100/0     | 11.68% | 12.0% | -49.0% | 0.80     | 0.24   | —            |
| 90/10     | 11.16% | 10.9% | -43.5% | 0.84     | 0.26   | 10.5pp       |
| 80/20     | 10.60% | 9.8%  | -37.7% | 0.88     | 0.28   | 10.5pp       |
| **70/30** | 10.01% | 8.8%  | -31.7% | **0.91** | 0.32   | 10.4pp       |
| **60/40** | 9.39%  | 7.9%  | -25.3% | **0.94** | 0.37   | 10.4pp       |
| 50/50     | 8.75%  | 7.1%  | -20.8% | **0.95** | 0.42   | 9.6pp        |
| 40/60     | 8.07%  | 6.5%  | -17.1% | 0.93     | 0.47   | 8.8pp        |

**判据：没有一档配置的 CAGR ≥ 100/0 而回撤更小。全部付费。**

汇率是 **10.4pp 回撤 / 1pp 年化收益**，而且非常稳定（各档几乎一致）。注意这是"价格指数"口径下测出的 20pp 的一半——加上股息后股票变强了，换回撤的成本翻倍。**别用不含股息的指数做配置决策**，会严重高估分散化的性价比。

Sharpe 在 50/50～60/40 达到峰值（0.94-0.95），Calmar 在 40/60 见顶（0.47）。**如果目标是风险调整后收益，60/40 附近是最优解；如果目标是绝对收益，就是 100/0。**

## 三、为什么"少赚了一点"——波动拖累在还账

|       | 波动    | 波动拖累（σ²/2） |
| ----- | ----- | ---------- |
| 100/0 | 12.0% | 0.72pp     |
| 70/30 | 8.8%  | 0.39pp     |

70/30 名义收益让渡 -1.67pp，但波动下降把 **0.34pp 的拖累还了回来**，实际几何收益只损失约 1.33pp，而回撤改善 17.4pp。

**这是"不减少收益减少回撤"的第一层真相：降波动本身是能创造收益的**，只是量级（0.3-0.7pp）远不足以抵掉让渡的票息（1.7pp）。它能让这笔交易变得更划算，但不能让它变成免费的。

## 四、定投视角：真正的答案在这里

前面都是"一次性投入"。但你是**定投者**——这两个视角的结论完全不同。

对定投者，中途的账面回撤不是风险，是**打折买入**。你唯一该怕的回撤是**最后一公里**：钱已经攒到接近目标时被打回去，因为你没有下一个 30 年来修复它。

滚动 30 年定投窗口（起点 1950-01～1996-08，全收益，每月再平衡）：

| 策略                    | 终值中位     | vs 纯股     | 最深浮亏  | **最后 5 年回撤** |
| --------------------- | -------- | --------- | ----- | ------------ |
| 100/0 纯股票             | 2198     | —         | -9.4% | **-20.1%**   |
| 80/20 恒定              | 1913     | -13.0%    | -6.7% | -15.7%       |
| 70/30 恒定              | 1853     | -15.7%    | -5.9% | -13.6%       |
| 下滑 100→50（末 10 年）     | 2103     | -4.3%     | -9.4% | -12.2%       |
| **下滑 100→30（末 10 年）** | **2089** | **-5.0%** | -9.4% | **-9.5%**    |
| 下滑 100→30（末 15 年）     | 2052     | -6.6%     | -9.4% | -8.5%        |

**最坏的 10 个窗口（1930 年代式、2008 式）：**

| 策略                    | 最差终值均值 | 最差"最后一公里"回撤 |
| --------------------- | ------ | ----------- |
| 100/0 纯股票             | 1392   | **-48.6%**  |
| 80/20 恒定              | 1172   | -38.6%      |
| **下滑 100→30（末 10 年）** | 1167   | **-26.1%**  |

### 三个结论

**1）下滑轨道严格优于任何恒定权重。**  
下滑 100→30 的终值（2089 / 最差 1167）与 80/20 恒定（1913 / 1172）相当甚至更好，但最后一公里回撤只有 -9.5% vs -15.7%，最坏情况 -26.1% vs -38.6%。  
**在终值相同的条件下，回撤只有恒定权重的一半。这不是权衡，这是免费午餐。**

**2）汇率从 10.4 提升到 62～132。**  
终值 -5.0% 摊到 30 年 ≈ 年化 -0.17pp。换来平均回撤改善 10.6pp、最坏情况改善 22.5pp。  
→ **每放弃 1pp 年化收益，换回 62pp（平均）/ 132pp（最坏）回撤。效率是固定权重的 6～12 倍。**

**3）原理不是择时，是风险预算的时序分配。**  
下滑轨道不预测市场，它只回答"我现在有多少钱可以亏"。钱少的时候（前 20 年）满仓承担风险，钱多的时候（后 10 年）降低风险。**同样是 30 年平均 80% 股票，把高风险期放在本金小的时候、低风险期放在本金大的时候，结果天差地别。**

## 五、集中度：你组合里真正的"免费风险"

这一节最该看。2000-01 至今：

|             | CAGR        | 波动        | 最大回撤       | Calmar   |
| ----------- | ----------- | --------- | ---------- | -------- |
| 纳指 100      | 8.26%（价格口径） | **22.9%** | **-81.1%** | 0.10     |
| 标普 500 全收益  | 8.47%       | 12.9%     | -49.0%     | **0.17** |
| 50/50 纳指+标普 | **8.58%**   | 15.9%     | -64.4%     | 0.13     |

**纳指 CAGR 并不比标普高（纳指价格口径 8.26%，加约 0.7% 股息后略高），但回撤是标普的 1.65 倍，Calmar 只有标普的 59%。**

定投 2000-01 至今（每月 1 份）：

|                 | 终值倍数       | 最深浮亏       |
| --------------- | ---------- | ---------- |
| 100% 纳指         | **12.09x** | **-54.0%** |
| 70% 纳指 + 30% 标普 | 9.98x      | -47.0%     |
| 100% 标普         | 6.20x      | -29.4%     |

互联网泡沫那一刀：

|        | 2000-03 → 2002-10 | 回本需要涨     |
| ------ | ----------------- | --------- |
| 纳指 100 | **-76.7%**        | **+329%** |
| 标普 500 | -37.8%            | +61%      |

### 这直接指向你的持仓

你持有 **A 股半导体个股（兆易创新、士兰微、风华高科、中际旭创）+ 纳指定投**。这两条腿：

- 都是**高 Beta 科技成长**
- 都吃**同一条 AI/半导体资本开支周期**
- 都受**同一个美联储流动性、同一套出口管制**影响

**这不是分散，这是把同一个赌注下了两次，还加了杠杆式的波动。** 你承担了近似单一赛道的风险（参考纳指 -81% 那一档），但拿到的预期收益并没有比分散化组合高多少。

**消除"不被定价的特异性风险"是唯一真正的免费午餐**——市场不会因为你集中持有一个赛道而给你额外补偿，但你确实付出了额外的回撤。把 A 股半导体个股部分换成/叠加 A 股宽基或红利、把纯纳指部分掺入标普或全球，是在**不降低预期收益的前提下降低回撤**。

## 六、落到你的执行层

你的画像：月到手 1.05 万、年奖金 3 万（全年 15.6 万）、未婚无子女、有应急金、风险承受强、期限长。

**结论：现在不需要降低股票权重。** 在累积期，回撤是朋友——你现在每月投入的量，相对 20 年后的本金微不足道，市场跌了你该高兴。

但要立刻做两件事：

### 1）分散化（免费，现在就做）

| 现状         | 建议                               | 目的                    |
| ---------- | -------------------------------- | --------------------- |
| 纳指 100 单一  | 纳指 / 标普（或全球宽基）配置，纳指不超过权益的 50-60% | 把 -81% 的尾部风险拉回 -50% 档 |
| A 股半导体个股集中 | 保留核心仓位，但权益部分叠加 A 股宽基 / 红利 / 黄金   | 切断"同涨同跌"              |

**具体比例取决于你对半导体赛道的 conviction，但原则是一条：任何单一赛道的权重不应超过权益资产的 30-40%。**

### 2）预设下滑轨道（不现在启动，但先把规则写下来）

触发条件（满足任一即启动）：

- 距离资金用途目标 ≤ 10 年
- 账户市值 ≥ 5 年开支

轨道设计（基于回测最优档）：

- **T-10 年：股票 100%**
- **每年降 7pp，T-1 年降至 30%**
- 每年再平衡一次；下降过程不因市场涨跌而中断（**不择时**）

回测预期：终值比"一路满仓"少约 5%（30 年累计），最后一公里回撤从 -20% 降到 -9.5%，最坏情况从 -49% 降到 -26%。

## 七、必须说清的边界

1. **Shiller 数据是标普，不是纳指。** 你的实际腿部波动（纳指 22.9%）远超标普（12.9%），所以上面所有"分散化 / 下滑轨道"的收益对你而言**只会更大，不会更小**。
2. **10Y 国债用久期近似（D=7.5）**，与真实总回报指数有偏差，尤其 2022 年。方向性结论不受影响。
3. **Shiller 价格是月均价**，波动被系统性低估约 15-20%，真实波动率更高 → 波动拖累更大 → 降低波动的价值被**低估**了。
4. **76 年样本里只有约 3 个独立的 30 年窗口**（不重叠），滚动窗口高度自相关。中位数是稳健的，尾部估计要打折看。
5. **不构成投资建议。** 币种、税务居民身份、跨境合规（QDII 额度、外汇额度、CRS）都未纳入。涉及具体产品和跨境结构，请与持证顾问及税务师确认。

## 附：回撤的非对称性（为什么回撤值得花代价去降）

| 回撤   | 回本需涨  |
| ---- | ----- |
| -10% | +11%  |
| -20% | +25%  |
| -30% | +43%  |
| -40% | +67%  |
| -50% | +100% |
| -60% | +150% |
| -70% | +233% |
| -80% | +400% |

亏得越深，修复成本呈**非线性**爆炸。这正是"每 1pp 收益换 10pp 回撤"这笔交易在长周期里仍然划算的原因——**回撤不是线性的，越深越致命**。
